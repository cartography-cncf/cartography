# LangSmith

The LangSmith module ingests the identity, access-control, and agent-credential surface
of [LangSmith](https://docs.langchain.com/langsmith/) and LangGraph Platform: who can do
what, and which agents hold which users' OAuth tokens.

See [configuration](config.md) for the token and permissions, [queries](queries.md) for
query examples, and the generated [schema](schema.md) for nodes and relationships.
